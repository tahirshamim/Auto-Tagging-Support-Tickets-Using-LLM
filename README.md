
# 🎫 Auto Tagging Support Tickets Using LLM

### 📌 Objective

Automatically classify support tickets into multiple categories using **large language models (LLMs)**.

### 📂 Dataset

* Free-text Support Ticket Dataset

### ⚙️ Methodology

* Implemented **zero-shot classification** using an LLM
* Improved accuracy with **few-shot learning** via prompt engineering
* Compared zero-shot vs few-shot performance
* Output **top 3 most probable tags** with confidence scores
* No model fine-tuning required

### 🛠️ Tools & Libraries

* Hugging Face Transformers
* Pretrained LLMs
* Prompt Engineering

### 📊 Output

* Ranked top-3 ticket categories per input
* Confidence scores for each tag

### 🎯 Skills Demonstrated

* Prompt engineering
* LLM-based text classification
* Zero-shot and few-shot learning
* Multi-class prediction and ranking
